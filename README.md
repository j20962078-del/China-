# China Fishing — Unity 6 / URP / Android (версия 0.6)

Мобильная 3D-игра про рыбалку, весь интерфейс на русском. Графика карты пока — временная «белая коробка»
из примитивов; модели по референсам будут добавлены позже.

## ЧЕСТНЫЙ СТАТУС
* Код **ни разу не компилировался и не запускался в Unity**, APK **не собран**.
* Выполнена только статическая проверка (`python3 tools/static_check.py .`): скобки, ссылки между классами,
  значения enum, целостность данных (11 рыб, 37 предметов). Это не компиляция.
* Первая облачная сборка покажет реальные ошибки компиляции — пришлите лог, и я их исправлю.

## Что нового в 0.8 — карта «Река Амур»
* Мир теперь строится по карте из архива `amur_game_map.zip`: тот же OBJ (110 000 вершин рельефа, деревья, домики, дороги, мостки, лодки), та же текстура-план. Ничего не упрощается и не пересчитывается: файлы лежат в `Assets/Resources/Amur` (`amur_game_map_obj.txt`, `map_texture_png.bytes`), оригиналы целиком — в `docs/maps/amur`.
* Рельеф режется на куски по 55×100 клеток (лучше работает отсечение). Коллайдер вдвое реже визуальной сетки, чтобы быстро собираться на телефоне. Вокруг карты плоские окрестности, игрок ограничен краем карты.
* Вода: уровень `AmurMap.WaterY` = 0,9. Игровая глубина = (уровень − дно) × `DepthScale` (8), потому что русло в модели мельче метра. На внешний вид это не влияет.
* Места для рыбалки находятся автоматически по водоёмам модели (с обоих берегов у крупных), плюс «Мостки» и «Домики». Окно «Карта» показывает план из архива с точками.
* Старая позиция игрока со старой карты сбрасывается один раз. Если файлов Амура в `Resources/Amur` нет, игра строит прежнее озеро.
* Известное: в модели русло вырезано в рельефе только местами (≈3,6 % клеток), а на плане река шире. Вода есть там, где она есть в модели; остальная нарисованная река — суша. Углубить русло по текстуре можно отдельным шагом.
* Код по-прежнему не компилировался в Unity. Разбор OBJ проверен отдельно (компилятор Mono) на настоящем файле.

## Что нового в 0.7 — 30 удилищ с 3D-моделями
* Вкладки магазина и инвентаря: **Фидерные · Карповые · Пикерные · Спиннинговые · Поплавочные · Маркерные** (по 5 удилищ). Старые 4 базовых удилища остались во вкладке «Удочки». Колонка вкладок теперь прокручивается.
* Карточки удилищ показывают 3D-превью модели (OBJ без костей из `Assets/Resources/Rods`), рисуется один раз и кэшируется. Работает фильтр по производителю.
* Выбранное удилище меняется в руке персонажа: торец рукояти за ладонью, вершинка вперёд, леска идёт от вершинки модели. У базовых удилищ без модели осталась простая процедурная удочка.
* Цвета берутся из `Resources/RodMtl/*.txt` (копии `.mtl`), потому что Unity не всегда подхватывает `.mtl` сам.
* Нагрузка, заброс, цена и уровень удилищ — игровой баланс в `GameData.cs` (блок «УДИЛИЩА С 3D-МОДЕЛЯМИ»), легко меняется.
* Пока НЕТ: изгиба удилища (GLB со скелетом и `RodBender.cs` в проект не подключены), катушки на модели, привязки навыков «Пикер»/«Маркер» к рыбалке.
* Код по-прежнему не компилировался в Unity (только `tools/static_check.py`).

## Что нового в 0.6 — «Настройки» с вкладками «Крафт» и «Навыки»
* Кнопка «Настройки» есть в главном меню и в игровом HUD (сверху справа). Окно имеет три вкладки: **Настройки · Крафт · Навыки**.
  Отдельной кнопки «Крафт» в главном меню больше нет.
* Навыки по ТЗ: Фидер, Карпфишинг, Пикер, Спиннинг, Поплавочная ловля, Маркер (каждые 5 пойманных рыб на свою снасть — +0,3%),
  Приготовление прикормки (каждые 6 замесов — +0,3%). Считаются только реально пойманные рыбы (сход, обрыв, пустой заброс — нет).
  Бонус реально прибавляется к эффективности клёва (и к силе прикормки для навыка приготовления).
* Соответствие снастей: донная оснастка → Фидер, донная с бойлом/пеллетсом → Карпфишинг, спиннинговая проводка → Спиннинг,
  поплавочная → Поплавочная ловля. Пикер и Маркер пока не растут: пикерных и маркерных удилищ в игре нет.
* Кнопки «Рюкзак/Карта/Настройки» в HUD стоят в ряд справа сверху; на узких экранах проверьте, что они не перекрывают сообщения.

## Что нового в 0.5 — прикормки, материалы и крафт

  крафта бойлов и монтажей; кнопки «Крафт» нет в игровом HUD (только в главном меню). Леща в игре нет — «лещовая» работает на сазана и карася.
* Код не компилировался в Unity (только статическая проверка).

## Что нового в 0.3 — магазин по подкатегориям
* Товары имеют поля `cat` (основная категория), `sub` (подкатегория), `maker` (производитель), `compat` (совместимость) — см. `GameData.cs`.
* Вкладки: Наживки, Приманки, Прикормки, Материалы (+ прежние). Внутри вкладки — секции с заголовком, тонкой линией и своей сеткой карточек
  в одном прокручиваемом списке. Порядок секций задан в `GameData.sections`; пустые секции не показываются;
  товар с неизвестной подкатегорией попадает в «Другое».
* Новый товар = одна строка `I(... , sub: "Черви")` — он сам появится в нужной секции, интерфейс менять не нужно.
* Карточка: иконка, название, тип, штук в упаковке, цена, производитель, значок «i». Нажатие открывает окно товара
  (характеристики, описание, совместимость, количество упаковок, «Купить»).
* Фильтр производителя появляется, только если у товаров категории задан `maker`; структура секций при этом сохраняется.
* Добавлено около 90 наживок и приманок из ТЗ (живцы, черви, личинки, жуки, тесто, натуральные насадки, тонущие бойлы, Pop-Up,
  пеллетс, искусственная кукуруза, воблеры по типам, блёсны, силикон). Рыба клюёт на них через «семейство» товара
  (`family`): например все черви наследуют предпочтения базового «worm». Размеры пеллетса (2–20 мм), прикормки, материалы
  и модели/текстуры наживок — ещё не сделаны, вкладка «Материалы» пока пустая. Код не компилировался в Unity (статическая проверка пройдена).

## Сборка APK в облаке Unity (Unity Build Automation) — рабочий путь с телефона
Unity больше не поддерживает ручную активацию личной лицензии, поэтому сборка через GitHub Actions (game-ci) для бесплатного
аккаунта не работает. Вместо неё: cloud.unity.com → проект → DevOps → Build Automation → подключить репозиторий GitHub →
новая цель сборки: платформа Android, версия Unity 6000.0.x. В «Advanced» указать
**Pre-export method:** `ChinaFishing.EditorTools.ProjectBuilder.Prepare` (создаёт сцену, URP, материалы и настройки игрока).
Бесплатно в месяц: 200 минут Windows и 100 минут Linux.

## (Устарело) Как получить APK с телефона через GitHub Actions
1. Зарегистрируйтесь на github.com, создайте **приватный** репозиторий.
2. Загрузите содержимое архива (Add file → Upload files), включая скрытую папку `.github` и папку `tools`.
3. **Лицензия Unity (один раз).** Actions → «1. Получить файл активации Unity» → Run workflow → скачайте артефакт
   `Unity_activation_file` (.alf). Откройте https://license.unity3d.com/manual , загрузите .alf, выберите Personal,
   скачайте .ulf. В репозитории: Settings → Secrets and variables → Actions → New repository secret:
   `UNITY_LICENSE` (всё содержимое .ulf), `UNITY_EMAIL`, `UNITY_PASSWORD`.
   Порядок лицензирования Unity мог измениться — если ручная активация недоступна, см. документацию GameCI
   (https://game.ci/docs/github/activation) и напишите мне.
4. Actions → «2. Собрать APK» → Run workflow. Первая сборка — десятки минут.
5. APK появится в разделе Releases репозитория (и в артефактах запуска). Скачайте и установите на телефон.
6. Если сборка упала: откройте лог шага «Сборка APK», найдите строки `error CS` и пришлите их.

Версия Unity: `6000.0.23f1` (в `ProjectSettings/ProjectVersion.txt` и в workflow). Если образ GameCI для неё
недоступен, замените версию в обоих местах на другую доступную 6000.0.x (URP 17.0.x).

## Если есть компьютер или облачный ПК
Откройте проект в Unity 6000.0.x (с модулем Android), меню **China Fishing → 1. Подготовить проект**, затем Play
или **2. Собрать APK**. Подготовку можно запускать повторно.

## Управление
Джойстик слева (вверх — вперёд), свайп по экрану — камера, два пальца справа — приближение, кнопка «Рыбалка» у воды.
Кнопки «Заброс» (удерживать) → «ПОДСЕЧКА!» при поклёвке → «Тянуть» (удерживать). Кнопка «Назад» Android закрывает окно
или возвращает в меню.

## Сохранения
JSON в папке приложения. Запись через временный файл с проверкой и резервной копией (`.bak`). Повреждённые файлы не
удаляются, а копируются рядом (`.corrupt_*`). Сброс прогресса делает копию (`.before_reset_*`).

## Качество графики
Низкое / Среднее / Высокое переключают разные URP-ассеты (тени, масштаб рендера, MSAA), дальность прорисовки, плотность
травы и лимит кадров 30/45/60 (на лету). Количество деревьев и камышей применяется при следующем запуске.

## Карта «Камышевское озеро» (заменила Амур)
- Игра строит мир из сцены Prisma 3D: дома с вывесками, мостки, дорога, камыши, кувшинки, лес, камни, трава, заборы, фонари, вода. Текстуры сцены сохранены (доски, гравий, камень, камыши, рогоз, кувшинки, трава, вывески).
- Данные: `Assets/Resources/Kamyshevskoe/` (`kam_scene.bytes`, `kam_height.bytes`, PNG-текстуры как `*.bytes`, `map_photo.bytes`). Код: `Assets/Scripts/World/KamMap.cs`, `BuildKamWorld` в `WorldBuilder.cs`.
- Окно «Карта» показывает фото `map_photo.bytes` (привязка игрока к фото подогнана по подписям домов).
- Исходник: `docs/maps/kamyshevskoe/kamyshevskoe_ozero.prisma`; конвертер: `tools/kam_export.py` (+ `kam_prisma_parse.py`).
- Если файлов `Resources/Kamyshevskoe` нет, игра откатывается на карту Амур или прежнее озеро.
- Статус: код не компилировался и не запускался в Unity — проверяется сборкой в GitHub Actions и на телефоне.
