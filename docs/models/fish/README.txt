FISH PACK для China Fishing — процедурные базовые модели рыб

Папки: <имя>/<имя>.glb, .obj, .mtl + PNG:
  <имя>_body.png (2048x1024), <имя>_body_normal.png (1024x512),
  <имя>_fin_d.png и <имя>_fin_p.png (512x512, с альфой)
Модели: 11 видов + карась золотой + трофейные сом, сазан, щука, окунь.
~24 тыс. треугольников на модель. Метры, нос +Z, верх +Y, PBR (GLB).
Длина = общая длина рыбы с хвостом (сом 1.5, белуга 2.2, осётр 1.2 и т.д.).

Unity 6: OBJ импортируется сразу (текстуры из папки). Для GLB нужен пакет glTFast
(Package Manager -> Add by name -> com.unity.cloud.gltfast).
Плавники — полупрозрачные карточки, материал: Surface Type = Transparent, Render Face = Both.

Это процедурная геометрия + процедурные текстуры (основа/плейсхолдер),
не художественный AAA-арт. Для финального качества используй промпты в Meshy/Tripo/Rodin.
